# Laboratorio Red Aula IaC

Laboratorio formativo de la Unidad 1 de IC106TICL — Automatización de Infraestructura con IaC.

## Propósito

Practicar el uso de Terraform, Git y AWS en un entorno autorizado, aplicando versionamiento, modularidad, verificación técnica y limpieza controlada de recursos.

## Entorno

- AWS Academy Learner Lab
- AWS CloudShell
- Terraform
- Git
- AWS CLI

## Importante

No versionar credenciales, secretos, claves privadas, archivos de state ni planes binarios.
